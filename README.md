# Hi_Hysteria (mirror)

一键安装/管理 [Hysteria2](https://github.com/apernet/hysteria) 服务端脚本。

这是原项目 `emptysuns/Hi_Hysteria` 的个人自托管镜像 —— 原作者账号与仓库已被删除，
本仓库基于本地保留的完整脚本文件重建，用于承载脚本自更新与多语言文件所需的远程资源。

## 安装

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/chenlee86/Hi_Hysteria/refs/heads/main/server/hy2.sh)
```

安装后可直接使用 `hihy` 命令打开管理菜单。

## 说明

- 内核使用官方 [apernet/hysteria](https://github.com/apernet/hysteria) release，与本仓库无关。
- `server/i18n/*.json` 为重建后的多语言文本，非原作者原文，如有生硬之处欢迎提 issue/PR 修正。
